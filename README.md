# vnkz.website
# 🚗 Portfólio Fotográfico Automotivo

Este projeto foi desenvolvido com o objetivo de criar um site portfólio moderno e responsivo para apresentar o trabalho de um fotógrafo especializado em fotografia automotiva.
A proposta foi construir uma interface visualmente atrativa, valorizando as imagens e proporcionando uma navegação agradável para os visitantes, com foco em destacar o trabalho profissional do cliente.

## 🔗 Acesse o projeto
👉 https://manuplens.github.io/vnkz.website/

## 💻 Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades
- Layout responsivo para diferentes dispositivos
- Galeria de imagens para apresentação do portfólio
- Interface moderna e intuitiva
- Estrutura otimizada para navegação visual
- Carrossel interativo em portfólio
- Visualização em Lightbox

## 📚 Objetivo do projeto
Este projeto foi desenvolvido com a finalidade de praticar e aprimorar habilidades em desenvolvimento web, aplicando conceitos de:
- Estruturação de páginas com HTML
- Estilização responsiva com CSS
- Interatividade com JavaScript
- Organização visual e experiência do usuário (UI/UX)

Além do aprendizado técnico, o projeto teve como objetivo entregar uma solução real para apresentação profissional de serviços fotográficos.
